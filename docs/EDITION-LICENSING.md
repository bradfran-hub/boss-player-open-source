# BOSS edition policy — owner direction, 28 October 2026

The owner's intended business model is a no-charge GPL option for GPL-compatible open-source projects and a paid BOSS offering at US$300 annually. This policy note is not a complete SDK licence agreement, a new source-code grant or a statement that all ownership/distribution checks have passed.

If permission to use BOSS-owned code in a closed-source application requires payment, the paid permission must be expressed as a separate commercial BOSS licence. Standard LGPL permits commercial use and redistribution without a recurring payment to the copyright owner. Charging for official downloads, updates or support is possible, but must not remove recipients' LGPL rights. No revenue-share percentage or minimum-against-percentage rule has been set here.

Existing GPL/LGPL grants remain in force. Any new commercial terms apply only where the BOSS owner has the necessary rights; they cannot restrict previously granted rights or override adapted third-party code.

## Both editions retain third-party obligations

- FFmpeg, VLC/libVLC, VLCKit and every other dependency retain their own licences. BOSS cannot sell an exception to another author's copyleft requirements.
- A free GPL distribution requires its applicable complete corresponding source and permitted distribution/installation terms. This dependency-only repository is not a complete BOSS GPL source release.
- A paid distribution using LGPL libraries still needs the applicable library source, changes, notices, relinking/replacement materials and recipient rights. Payment is not a substitute.
- Permissive dependencies still require their copyright/licence/NOTICE text and any other applicable conditions, including for model weights.
- Code already received under GPL/LGPL retains those rights; GPL code can also be used commercially if its conditions are met. Do not describe GPL as a ban on earning money.

Primary references: [GNU on selling GPL exceptions](https://www.gnu.org/philosophy/selling-exceptions.html), [GNU GPL/LGPL FAQ](https://www.gnu.org/licenses/gpl-faq.en.html), [FFmpeg legal guidance](https://ffmpeg.org/legal.html).

The final commercial agreement and the complete Free source release are not published by this repository. No new paid agreement is accepted or sold here.
